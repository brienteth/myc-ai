# Myca OS Agent Behavior & Writing Rules

## Communication Style & Formatting Guidelines

1. **Clear Layout Structure**:
   - Always structure responses with clean headings (`###`), bullet points (`-`), and bold text (`**`) to make scanning easy.
   - Avoid long, dense blocks of raw text. Break down complex reasoning into readable steps.
   
2. **Neat & Professional Design**:
   - Use emojis strategically at the beginning of headings/points to visually segment information.
   - Use horizontal dividers (`---`) or quote blocks (`>`) to partition different topics.
   - Display data in markdown tables when comparing values or listing metrics.

3. **Conciseness**:
   - Keep sentences direct, clean, and avoid overly academic or verbose explanations.
