## 🚀 Google Chrome'a Yükleme Adımları (Installation Guide)

1. **Google Chrome'u açın.**
2. Adres çubuğuna şunu yazıp Enter'a basın:
   ```text
   chrome://extensions/
   ```
3. Sağ üst köşedeki **"Geliştirici modu" (Developer mode)** anahtarını **AÇIK (ON)** duruma getirin.
4. Sol üstte beliren **"Paketlenmemiş öğe yükle" (Load unpacked)** butonuna tıklayın.
5. Açılan dosya seçiciden şu klasörü seçin:
   ```text
   /Users/bl10buer/Desktop/myc-network/chrome-extension
   ```
6. **Tebrikler!** "MYCA Sovereign Wallet" eklentiniz yüklendi. Chrome araç çubuğundaki yapboz (Extensions) simgesine tıklayıp sabitleyebilirsiniz (Pin).
