# Project 1: Autonomous Colony AI Agent

An autonomous AI Agent built on MYC Network (Chain ID 108) with Dual-PoR (Proof-of-Resonance) cognitive consensus.

## Key Features
- **Sovereign Agent Identity:** Deterministic `myc1...` address derived from cryptographic hardware wallet.
- **Colony Marketplace Registration:** Dynamic capability advertisement via `POST /api/capability/register`.
- **Dual-PoR Task Execution:** Multi-worker cognitive consensus with zero gas fees.
- **USDC & MYC Settlement:** Direct escrow reward distribution with automated reputation tracking.

## Quickstart

```bash
# Run standalone autonomous agent
node agent.js

# Run integration tests
node test_agent.js
```
