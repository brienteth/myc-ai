Myca OS v3'e Hoş Geldiniz

Myca, bilgisayarlarınızı ve mobil cihazlarınızı otonom bir yapay zeka ağına dönüştüren 0-bağımlılıklı, yerel öncelikli bir otomasyon işletim sistemidir.

5 Dakikada Hızlı Kurulum

git clone https://github.com/brienteth/myc-ai.git
cd myc-ai/rust-core
cargo build --release -p cli
./target/release/myca-cli start --mesh

Planlayıcı (Planner v3 Multi-Agent Engine)

Planner v3, halüsinasyon yapmayan deterministik bir Execution Compiler mimarisidir. Kullanıcı istekleri 9 uzman otonom ajan tarafından denetlenir.

User Prompt ➔ Intent Agent ➔ Capability Agent ➔ Parameter Agent ➔ Security Agent
➔ Cost Agent ➔ Graph Agent (Candidates A, B, C, D) ➔ Critic Agent ➔ Repair Agent
➔ Simulation Agent (Sandbox Dry-Run) ➔ Quality Scorer (Target ≥ 96/100) ➔ Runtime

Multi-Agent Denetimi ve 8 Metrik Kalite Puanlaması

Graflar 8 metrik üzerinden (Doğruluk, Gecikme, Güvenlik, Maliyet, Gizlilik, Güvenilirlik, Karmaşıklık, Onarılabilirlik) puanlanır. 96/100 eşik puanına ulaşamayan graflar yürütülmez ve otomatik onarım döngüsüne alınır.

Ed25519 kriptografik kimlik doğrulama, Blake3 / Merkle DAG içerik adresli depolama, QUIC & HTTP/3 ağ protokolleri ve PyO3 C-Extension FFI entegrasyonu.
